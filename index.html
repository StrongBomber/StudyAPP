AI asistanını güvenle bağla

API anahtarını bu sayfaya yazma. Anahtar yalnızca sunucudaki .env dosyasında saklanır.

  1. Şablonu sunucuya kopyala. .env.example dosyasını hostingde .env adıyla kopyala (yoksa yeni dosya oluştur).
  2. Yalnızca sunucu dosyasını düzenle. API_KEY= satırına API anahtarını ekle ve AI_ENABLED=true bırak.
  3. Kaydet, sonra yenile. “Kaydettim — test et” düğmesiyle ayarları doğrula.
.env örneği
AI_ENABLED=true
API_KEY=
AI_RATE_LIMIT_PER_HOUR=30
Gerçek anahtarı yalnızca sunucudaki .env dosyasına yaz. Bu dosyanın web üzerinden indirilmesi engellenir.
